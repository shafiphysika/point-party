# Hero passports and the class name wheel

Lucky pick includes a fifth effect, Name wheel. It builds equal slices from the selected class's present learners, excludes already-picked seats in everyone-gets-a-turn mode, and starts a fresh round after all present learners have had a turn. Full names are listed below the wheel; long slice labels are shortened. Existing unbiased crypto selection chooses the winner; rotation only illustrates that result. The final wheel remains visible until another draw or navigation. A school/class/page change cancels a pending draw. A spin never awards points automatically.

Students have original vector storybook heroes, with six visual variants assigned deterministically by class and seat. These are decorative characters, not portraits or inferred student characteristics. Capes and stars move gently, with an operating-system reduced-motion fallback.

Choose Students → Hero profiles, then a learner, to open their passport. It derives the title, treasure milestones, points and next treasure from current points. Fourteen superpower cards count exact positive skill awards in existing recent records (up to 30 saved entries per learner); these counts are not lifetime totals. The Celebrate button changes no records. Existing points permission gates the +1 control, and existing class projection limits whose profiles and names are available.

No new schema, authentication provider, third-party animation runtime or external student-data transmission is added. Current badges reflect current point totals, so reducing/resetting points may relock milestones. Original pets and all four dice effects remain available.

Academoo's public name-wheel and star-chart concepts informed the feature selection. Its artwork, game code and assets are not included. Animos-style motion is implemented with original CSS/SVG rather than exported templates.

Validation: wheel angle tests cover every winner in classes of 1–60; UI tests cover class isolation, attendance, no-repeat selection, repeated spins, cancellation, profile rendering and denied point awards. Browser previews use synthetic learners only; never upload preview HTML or private backups to the public repository.
